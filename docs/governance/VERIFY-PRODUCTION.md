## 1. הבאנר לא נחתך ולא נכנס מתחת לסייד-בר

זו הייתה הבעיה: הבאנר נמתח מתחת לסייד-בר ו-208 פיקסלים מההודעה הוסתרו.

**בדיקה ידנית:** המשפט המלא נקרא מתחילתו ועד סופו, ואף חלק ממנו לא נעלם מתחת לתפריט הצדדי.

**בדיקה מדויקת** (Console):

```js
const b = document.querySelector('.account-grace-banner');
const s = document.querySelector('.sidebar');
if (!b) console.log('אין באנר במסך הזה — היכנס לחשבון עם חוב פתוח');
else {
  const rb = b.getBoundingClientRect(), rs = s ? s.getBoundingClientRect() : null;
  const overlap = rs && getComputedStyle(s).display !== 'none' ? Math.round(rb.right - rs.left) : 0;
  console.log('חפיפה לסייד-בר:', Math.max(0, overlap), 'px — חייב להיות 0');
  console.log('חורג מהמסך:', Math.round(rb.right - window.innerWidth), 'px — חייב להיות <= 0');
}
```

**חזור על זה בשלושה רוחבים** (גרור את גבול החלון): רחב מ-1050, בין 760 ל-1050, וצר מ-760. בכל השלושה החפיפה חייבת להיות 0.

## 2. "יציאה" ממורכז ובגודל שכניו

```js
const so = document.querySelector('.sign-out-button');
const r = so.getBoundingClientRect();
const range = document.createRange(); range.selectNodeContents(so);
const rt = range.getBoundingClientRect();
const top = Math.round(rt.top - r.top), bottom = Math.round(r.bottom - rt.bottom);
console.log('גובה הכפתור:', Math.round(r.height), '(אמור 48)');
console.log('מרווח מלמעלה:', top, 'מלמטה:', bottom, '— אמורים להיות שווים');
```

## 3. כל טרנזקציה נושאת תאריך ושעה

| מסך | איפה | מה אמור להופיע |
|---|---|---|
| שכר → היסטוריית סגירות | תחת כל חודש | `שולם 09.08.2026 · נסגר 16.08.2026, 06:10` |
| שכר → פירוט לפי חודש | תחת כל שורה | `נשמר` + תאריך ושעה |
| פורטל העובד → תשלומים | בכרטיס | תאריך תשלום, ושעת האישור |
| קלסר חירום → היסטוריית תשלומים | עמודות | `תאריך תשלום`, `נסגר בתאריך ובשעה` |

הפורמט תמיד `dd.mm.yyyy` ושעון 24. **אם מופיע תאריך בפורמט `2026-08-09` — זה מסך שפספסנו, דווח.**

## 4. ההתכתבות מראה מי ומתי

| מסך | מה אמור להופיע |
|---|---|
| פורטל העובד → בקשות | `נשלח על ידך`, `נשלח <תאריך ושעה>`, ואם נענתה — `נענה <תאריך ושעה>` |
| תיק העסקה → בקשות העובד | `מהמטפל/ת`, `התקבל …`, `טופל …` |
| תיק העסקה → היסטוריית סטטוסים | `שונה על ידי <שם>` + תאריך ושעה בכל שורה |
| תיק העסקה → כרטיס הסלמה | `נפתח …`, ואם נסגר — `נסגר …` |
| תיק העסקה → ציר זמן | `בוצע על ידי <שם>` |

## 5. הנתונים קיימים — לא רק נראים

הרץ ב-Supabase → SQL Editor את `database/VERIFY-DATA-EXISTS.sql` (קריאה בלבד, אין בו שום שינוי).
**החלקים הקריטיים:** חלק 1 (ספירת שורות בכל טבלה) וחלק 4 (לאיזה tenant המשתמש מקושר וכמה תיקים יש בו).

> אם מסך מציג "אין נתונים" אבל השאילתה מראה שורות — זו **בעיית הצגה, לא מחיקה**. הסיבה השכיחה: חשבון חדש שנפתח מקבל tenant חדש וריק, בעוד הנתונים יושבים תחת ה-tenant הישן.
