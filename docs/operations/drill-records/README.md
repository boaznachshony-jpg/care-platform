# רישומי תרגילי שחזור

**תרגיל שלא נרשם לא התרחש.**

כל הרצה של תרגיל שחזור — א' או ב' — מקבלת קובץ אחד בתיקייה הזו, בשם
`YYYY-MM-DD-restore-drill.md`.

הרישום אינו פורמליות. הוא המקום היחיד שבו ה-RTO מפסיק להיות מספר שנכתב
במסמכי תפעול ומתחיל להיות מספר שנמדד. עד שיש כאן קובץ אחד לפחות,
`RESTORE-DRILL.md` פותח במשפט שהוא עדיין נכון: גיבוי שלא שוחזר מעולם אינו
גיבוי — הוא הנחה.

## תבנית

העתק את `_TEMPLATE.md`, מלא, ואל תמחק שדה שלא ידעת למלא — כתוב בו
"לא נמדד". שדה ריק נראה כמו השמטה; "לא נמדד" הוא ממצא.
